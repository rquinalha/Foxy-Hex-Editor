# Foxy Hex Editor v1.0.2

English text below | Texto em Português abaixo

## 🇺🇸 English Version

### Fixes and improvements

Fixed an issue where text editing could keep the cursor in place after typing with custom character tables.

Fixed a case where the text panel could inherit partial hex-edit state when switching from hex editing to text editing.

Improved cursor advancement when typing text mapped through the active custom table.

Improved text editing consistency between standard ASCII mode and custom table mode.

## 🇧🇷 Versão em Português

### Correções e melhorias

Corrigido o problema em que a edição de texto podia manter o cursor parado após digitar usando tabelas customizadas.

Corrigido um caso em que o painel de texto podia herdar o estado parcial da edição hexadecimal ao alternar da edição hex para a edição de texto.

Melhorado o avanço do cursor ao digitar texto mapeado pela tabela customizada ativa.

Melhorada a consistência da edição de texto entre o modo ASCII padrão e o modo com tabela customizada.
